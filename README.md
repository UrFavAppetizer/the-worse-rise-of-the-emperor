# THE WORSE: RISE OF THE EMPEROR

Campaign website source for Envy Emperor.

## Files

- `index.html` is the standalone site entry point and can be served from the repository root.
- `the-worse-source-v3.tar.gz` contains the full Sites source layout, including `dist/index.html` and `.openai/hosting.json`.
- `.gitignore` keeps local packaging output out of version control.

## Live site

https://the-worse-rise-of-the-emperor.wakingdove.chatgpt.site/

The novel writing area stores drafts in the current browser's local storage. Draft text is not included in this repository.
